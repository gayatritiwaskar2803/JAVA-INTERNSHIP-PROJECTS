🚀 1. Smart Task Scheduler
📖 Overview

Smart Task Scheduler is a Java-based project designed to help users manage, organize, and prioritize their tasks efficiently.
It uses priority-based scheduling, automatic alerts, conflict detection, and helps improve productivity.

✨ Features

Add, update & delete tasks

Automatic task scheduling based on priority

Conflict detection

Deadline reminders

Task categorization

Simple and clean Java architecture

🛠️ Tech Stack

Java

Core OOP principles

Collections Framework

📦 How to Run

Extract the folder

Open project in IntelliJ / Eclipse / VS Code

Run the main file:

src/com/app/MainApp.java

🎓 2. College Admission System
📖 Overview

College Admission System is a Java project for managing college admissions through console interface.
It includes modules for students, courses, applications, and merit-based admissions.

✨ Features

Add & manage students

Add & manage courses

Apply for courses

Merit-based admission processing

View all applications, students, and courses

Clean modular design

🛠️ Tech Stack

Java

OOP concepts

ArrayList & HashMap based storage

📦 How to Run

Extract the folder

Open in any Java IDE

Run:

src/com/app/MainApp.java
